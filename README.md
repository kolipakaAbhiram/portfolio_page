# Abhiram Kolipaka — Portfolio

Plain HTML/CSS/JS. No install or build step.

## Files
- `index.html`   page structure (section titles live here)
- `css/style.css`  colors and design (change theme colors in `:root` at the top)
- `js/data.js`   **ALL your content** — edit this to update text, projects, skills, links
- `js/main.js`   page logic (rarely needs changes)
- `assets/profile.jpg`  your photo (replace with a better one using the same name)
- add `Abhiram_Kolipaka_Resume.pdf` in the same folder as `index.html`

## Common edits
- New project: copy a block inside `projects` in `js/data.js`
- New skill: add a name to an `items` list in `skills`
- New certificate: add a block inside `certs`
- Preview: double-click `index.html`

## Publish (GitHub Pages)
Upload everything in this folder to a repo, then Settings > Pages > Deploy from branch > main / root.
